# Zkolar: Architecture & Repo Structure Guide

**Project:** Zkolar (Zero-Knowledge Academic Credential Protocol)

**Description:** A privacy-preserving academic credential protocol using ZK-SNARKs to prove qualifications without revealing raw data.

**Repository Strategy:** Monorepo (Hybrid Sol/Circom)

---

## 1. Directory Structure (The "Senior" Layout)

We use a Monorepo approach. The off-chain privacy logic (`circuits`) lives next to the on-chain execution logic (`src`), bridged by automation scripts.

```text
Zkolar/
├── .gitignore               <-- CRITICAL: Must ignore heavy ZK build artifacts
├── foundry.toml             <-- Foundry Config
├── package.json             <-- NPM dependencies (circomlib, snarkjs)
├── README.md                <-- Documentation
│
├── circuits/                <-- THE OFF-CHAIN WORLD (Private)
│   ├── grade_check.circom   <-- The Logic: "Input A > Input B"
│   ├── input.json           <-- Dummy data for testing the circuit
│   └── build/               <-- (GitIgnored) Compiled .wasm, .zkey, .r1cs
│
├── scripts/                 <-- THE GLUE (Automation)
│   ├── compile_circuit.sh   <-- Script to compile circom & generate Verifier.sol
│   └── generate_proof.js    <-- The "User App": Takes inputs, spits out proof.json
│
├── src/                     <-- THE ON-CHAIN WORLD (Public)
│   ├── Zkolar.sol           <-- Main Contract (Stores Commitments)
│   ├── Verifier.sol         <-- Auto-generated by SnarkJS (Do not edit manually)
│   └── interfaces/          <-- IVerifier.sol (Optional, for cleanliness)
│
└── test/                    <-- THE INTEGRATION
    └── Zkolar.t.sol         <-- Foundry tests that simulate the full flow
```

## 2. Component Logic Breakdown

### A. The Circuit (`circuits/`)

This is the "Truth Machine." It runs on the user's computer, not the blockchain.

- **`grade_check.circom`**:
  - **Inputs:** `actualGPA` (Private), `salt` (Private), `threshold` (Public), `identityHash` (Public).
  - **Logic:**
    1.  **Range Proof:** Assert `actualGPA >= threshold`.
    2.  **Integrity Proof:** Assert `Poseidon(actualGPA, salt) == identityHash`.

### B. The Smart Contract (`src/`)

This is the "Verification Machine." It runs on Ethereum/EVM.

- **`Verifier.sol`**: You do not write this. `snarkjs` generates it. It contains the mathematical constants to check if a proof is valid.
- **`Zkolar.sol`**: You write this.
  - **Struct:** `StudentData { bytes32 commitment; bool hasCredential; }`
  - **Logic:** Stores the University's "Commitment" to the student's grade. Calls `Verifier.verifyProof()` when an Employer asks.

### C. The Glue Scripts (`scripts/`)

This is what makes you look like a Lead Engineer. You automate the boring stuff.

- **`compile_circuit.sh`**:
  - Runs `circom`.
  - Runs `snarkjs` setup (Phase 1 & 2).
  - Exports `Verifier.sol`.
  - **Crucial Step:** Automatically copies `Verifier.sol` into the `src/` folder so Foundry can see it.

## 3. The Development Workflow (Step-by-Step)

When you sit down to work, follow this order to avoid confusion:

**Phase 1: Setup (The Foundation)**

1.  Initialize Foundry (`forge init --force`).
2.  Initialize NPM (`npm init -y`).
3.  Install ZK libraries: `npm install circomlib snarkjs`.

**Phase 2: The Circuit (The Math)**

1.  Write `circuits/grade_check.circom`.
2.  Compile it manually first to ensure no errors.
3.  Generate the "Trusted Setup" keys (the `.zkey` files).

**Phase 3: The Contract (The Code)**

1.  Export the `Verifier.sol` from your circuit.
2.  Write `src/Zkolar.sol`.
3.  Import `Verifier.sol` into `Zkolar.sol`.

**Phase 4: The Test (The Proof)**

1.  Write a test in `test/Zkolar.t.sol`.
2.  **Mocking:** For the first version, you don't need to generate a real proof inside the test (that requires FFI and is hard).
    - _Senior Cheat:_ Just verify that `Zkolar.sol` correctly calls `Verifier.sol`.
    - _God Mode:_ Use a script to generate a valid `proof.json` and feed it into the test.

## 4. The `.gitignore` Rules (Crucial)

If you commit a 100MB `.zkey` file to GitHub, you will regret it. Add this immediately:

```text
# ZK Artifacts
circuits/build/
*.r1cs
*.zkey
*.ptau
*.wasm

# Node
node_modules/

# Foundry
out/
cache/
broadcast/
```
